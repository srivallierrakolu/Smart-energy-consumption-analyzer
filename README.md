# Smart Energy Consumption Analyzer

## 📌 About the Project

The Smart Energy Consumption Analyzer is a Python-based project that calculates the electrical energy consumed by different appliances based on their power rating and usage time.

The project also generates a bar graph to compare the energy consumption of different appliances.

## 🎯 Objective

The objective of this project is to provide a simple way to calculate and understand electricity consumption using Python.

## ⚙️ How It Works

1. The user enters the number of appliances.
2. The appliance name is entered.
3. The power rating is entered in Watts.
4. The daily usage time is entered in hours.
5. The number of days is entered.
6. The program calculates energy consumption in kWh.
7. A bar graph displays the energy consumption of each appliance.

## 🧮 Formula

Energy Consumption (kWh) =

Power (W) × Usage Time (hours) × Number of Days / 1000
